Security Rules

Apply these rules in your Firebase Console → Realtime Database → Rules so only signed-in admins can write data, while product pages stay publicly readable. Product images are compressed and stored as base64 strings inside products — no Firebase Storage setup is needed.

{
  "rules": {
    "products": { ".read": true, ".write": "auth != null" },
    "categories": { ".read": true, ".write": "auth != null" },
    "orders": {
      ".read": "auth != null",
      ".write": true,
      ".indexOn": ["createdAt","status"]
    },
    "customers": { ".read": "auth != null", ".write": true },
    "settings": { ".read": true, ".write": "auth != null" }
  }
}

Note: "orders" write is public so customers can submit orders from the storefront; restrict further with App Check or a Cloud Function for production hardening. Keep product photos reasonably small (the editor auto-compresses uploads) since Realtime Database performs best with compact string values.
